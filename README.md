# Neon Pong

Projeto de Pong para monitor controlado por Arduino, com dois joysticks e três botões.

## Planejado

- 1 Player contra CPU
- 2 Players local
- Dificuldades da CPU
- Especiais por jogador
- Sorteio do especial da CPU
- Placar e tela de vitória
- Ranking e recordes
- Integração Arduino + Web

> O projeto está em desenvolvimento. A versão atual foca no visual e no fluxo das telas; a integração com Arduino e o backend de recordes entram nas próximas etapas.
